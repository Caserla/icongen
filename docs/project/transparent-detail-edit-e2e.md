## 2026-09-03：父版本 Alpha 继承回归

- 纠正问题范围：App 设置图标的初始方案 1、2、3 均为干净的真实透明 PNG；污染只发生在部分细节调整结果，不修改首次生成链路。
- 根因：旧后处理用 `dest-in` 将新图自身受污染的 Alpha 与圆角蒙版相乘，只能二次裁切，不能恢复初始方案的干净边界。
- 修复：圆角/圆形 App 插画图标在细节调整结束后，按输出尺寸读取父版本 Alpha，并逐像素替换新图 Alpha；方形背景和独立透明主体不套用该规则。
