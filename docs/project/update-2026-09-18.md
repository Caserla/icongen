# 2026-09-18 项目级 SVG 图标工作区交接

## 本轮目标

本轮把 `/create` 从单一预览页扩展为与项目关联的 SVG 图标生成工作区，并围绕“UI 交互响应优先”补齐主题、批量生成、画布操作、持久化、收藏回收和恢复闭环。素材库与图标生成仍是两个独立业务模块，数据不得互相复用。

## 已落地能力

### 项目与主题

- 创建、关联和切换项目；生成期间禁止新建或切换项目。
- AI 推荐成功后自动保存项目主题，预设列表依次展示智能推荐、唯一自定义主题和系统预设。
- 自定义主题覆盖上一次保存值，保存后工具栏主题图标立即更新。
- 未关联项目时四色默认选中系统第一项。
- 智能配色默认开启；手动模式按子风格能力显示单色或渐变拾色器，多色风格不支持手动配色。
- 智能配色只参考项目四色的品牌关系，不强制从四个色槽直接取色；事物固有颜色和子风格语义优先。

### SVG 生成链路

- 流程为：需求解析 → 确定图标清单 → 结构规划 → 生成标准 SVG → 校验与必要修正 → 逐个展示。
- 需求解析器只解析用户意图，不优化、替换或改变用户意图；默认语境是 App/SaaS 交互图标。
- 46 个子风格分别维护风格契约，并使用对应 24 图标参考板作为视觉证据。
- 参考板和风格契约预读取并缓存，避免批量任务对每个图标重复视觉解析。
- 默认规划与绘制模型为 `gpt-5.6-sol`；环境变量 `ICON_PLANNER_MODEL`、`ICON_SVG_MODEL` 可覆盖。
- 同一批智能配色保持一致的配色策略；手动配色实时同步预览，切换风格或切回智能配色恢复默认。
- 浏览器标签页内全局最多同时执行 6 个 SVG 任务；等待和生成均使用对应数量的骨架屏，数量未解析前不提前展示占位。

### 画布与图组

- 项目生成结果自动保存，重新进入项目时分页回显，超过 50 组继续加载且保持历史位置。
- 每行最多 5 列，图组宽度按实际图标数自适应。
- 支持选择、平移、触控板缩放、图组拖动、双击平滑聚焦、单图居中放大、自动整理和弱粘性对齐。
- 选择图组后图层置顶；操作按钮竖排显示在图组外侧。
- 平移和触控板手势在图标、图组操作栏上仍可工作。
- 图组位置持久化；回收、恢复和删除单图不会让其它图组重新排版。

### 收藏与回收

- 图组和单图分别支持项目级收藏、回收和恢复。
- 图组收藏/回收与单图收藏/回收都在接口和交互层互斥；冲突操作保留位置但显示不可交互状态。
- 单图组只有一个图标时按单图处理。
- 收藏夹和废纸篓复用统一固定高度弹窗，分别提供图组与单图分类。
- 回收操作立即从画布消失，接口失败回滚并显示吐司；恢复操作立即关闭弹窗，后台成功后在原位显示并平滑定位。

### 公共组件与性能

- 创建页、素材库、我的图标与后台复用 `WorkspaceHeader`。
- 收藏和回收弹窗复用 `ProjectCollectionDialog`。
- 图组/单图收藏回收转换、分页合并、粘性对齐和生成并发限制已提取为独立模块。
- 图组拖动通过 `requestAnimationFrame` 合并更新；画布平移不会重建全部 SVG 结果。
- 服务端资源按图组预聚合，避免图组数 × 图标数的重复扫描。

## 数据库与接口

- 项目和主题迁移：`0033`–`0038`。
- SVG 图组、位置、收藏与回收迁移：`0039`–`0044`。
- 主要接口：
  - `/api/projects`
  - `/api/projects/[projectId]/theme`
  - `/api/projects/[projectId]/svg-sets`
  - `/api/projects/[projectId]/svg-sets/[setId]`
  - `/api/projects/[projectId]/svg-sets/[setId]/position`
  - `/api/projects/[projectId]/svg-sets/[setId]/icons/[subjectId]`
  - `/api/projects/[projectId]/recycle-bin`
  - `/api/generation/icon-plan`
  - `/api/generation/svg-icon`
