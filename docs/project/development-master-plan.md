- 完整运营后台、数据看板、复杂用户管理、设置在线编辑器和模型管理 UI。
- 高级 266 项设置、参考图、SVG、Icon Font、Figma 或原生工程导出。
- 订阅制、公开促销码、团队空间、作品社区和浏览器内图标编辑器。

## 6. 更新流程

1. 开始任务前确认 ID、依赖和验收标准。
2. 代码、测试和文档全部完成后才能标记 `已完成`。
3. 更新状态时填写实际完成日期，不删除原计划日期。
4. 新增需求必须先判断属于第几期，再新增唯一任务 ID；禁止只写在聊天记录。
5. 每次提交前运行类型检查、测试、Lint 和文档一致性检查。
