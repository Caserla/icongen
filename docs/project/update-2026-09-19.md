# 2026-09-19 图标生成工作区交互与数据闭环交接

## 本轮范围

本轮在 2026-09-18 项目级 SVG 图标工作区基础上，继续收口 `/create` 的公共导航、项目编辑、画布聚焦、收藏回收、永久删除、输入区配色与操作提示。实现继续遵守“UI 交互响应优先”：可恢复操作优先局部乐观更新，不通过整页刷新同步状态；不可逆删除使用明确的二次弹窗确认。

## 已落地改动

### 公共导航与主题

- 所有工作区页面继续复用 `WorkspaceHeader`，英文入口由 `Icon generator` 缩写为 `Icon Gen`。
- 顶部导航拆分为左侧品牌与右侧导航/账户两个独立毛玻璃容器，中间完全透明；中英文切换不改变右侧容器宽度。
- 主题切换按钮、头像和导航容器使用统一边框色；个人信息菜单对齐导航右侧并使用增强毛玻璃效果。
- 深浅主题共享语义化玻璃表面、边框和模糊参数。

### 项目创建、关联与维护

- 项目输入会区分新项目与已有项目：新项目显示回车图标并打开新建弹窗，已有项目显示编辑图标并打开同款编辑弹窗。
- 项目名称更新只修改项目记录，不改变项目 ID；已有图标组继续按项目 ID 加载。
- 项目菜单 hover 仅移动文字，不增加背景；右侧删除入口使用确认弹窗。
- 新增项目、编辑项目、选择项目三个按钮均提供 hover/focus tip。
- 项目 PATCH/DELETE 继续按当前用户和项目 ID 做服务端归属校验。

### 画布与图组交互

- 选择模式下单击单图会以单图中心平滑聚焦并适当放大；双击图组保持图组聚焦。
- 平移模式双击图组或单图会先切换为选择模式，再平滑聚焦对应目标；轻微拖动不会误判双击。
- 自动整理以风格预览图正下方为基准，并在完成后聚焦整理范围。
- 图组与单图操作按钮仅在真实请求处理中显示等待鼠标；因收藏/回收互斥而禁用时使用普通禁用指针。
- 删除或回收单图保留原图组布局槽位，避免其它图组和组内元素跳位。

### 收藏、回收与永久删除

- 收藏夹、废纸篓继续复用固定高度的 `ProjectCollectionDialog`，图组和单图分类互相独立。
- 单图收藏 × 按钮增加“取消收藏 / Remove favorite”提示。
- 图组与单图回收列表支持恢复和永久删除，两个按钮各占一半宽度。
- 永久删除采用两次实际模态弹窗：第一次确认删除意图，第二次明确不可恢复；只有第二次确认才发送 DELETE。
- 第一次确认使用黄色感叹号，Continue 使用红色危险按钮；第二次确认使用红色危险提示。
- 单图永久删除同步更新图组 plan；删除最后一张单图时删除整个图组。前端只更新受影响的图组、选择和位置状态。
- 新增 `0045_project_svg_icon_delete_policy.sql`，允许用户删除自己项目图组下的单图；bootstrap 已同步该策略。

### 输入区与拾色器

- 智能配色开关位于发送按钮左侧，手动拾色器位于智能配色左侧。
- 单色拾色器整块区域均可触发，不再只有色块可点；箭头按展开状态旋转。
- Swatches/Custom 标签等宽撑满容器；主题拾色器继续使用统一圆角和深浅主题样式。
- 切换中英文不会重建画布预览层级或改变预览图状态。

## 接口与数据库

- `PATCH /api/projects/[projectId]`：编辑项目名称和简介。
- `DELETE /api/projects/[projectId]`：删除项目及其项目级资源。
- `DELETE /api/projects/[projectId]/svg-sets/[setId]`：永久删除图组。
- `DELETE /api/projects/[projectId]/svg-sets/[setId]/icons/[subjectId]`：永久删除单图；最后一图转为删除图组。
- 新增迁移：`infra/supabase/migrations/0045_project_svg_icon_delete_policy.sql`。
