# 待确认事项

本文只保留尚未冻结、会影响 MVP 开发或海外上线的事项。已经确定的需求不再混入待确认清单。

## 1. 接入真实服务前需要提供或确认

### Q1 平台生产配置

以下不是普通用户配置项，而是 Bamboo IconGen 运营方在服务端配置：

- OpenAI 项目 API Key、模型访问权限和月度成本上限。
- Stripe 生产账户、三个点数包的 Price ID、Webhook Secret。
- 邮件发送域名、发件人名称与邮箱，用于验证邮件和密码重置。
- 对象存储、私有 Bucket、签名下载域名和生命周期清理策略。
- 生产域名、DNS、SSL、错误监控和告警接收地址。

当前已冻结模型为 `gpt-image-2`、`medium` 质量；配置缺失时只能运行模拟生成流程。

### Q2 支持邮箱和法务主体信息

上线页面需要以下实际信息：

- 产品正式名称、运营公司或个人主体名称与联系地址。
- 支持邮箱、隐私请求邮箱。
- 服务条款、隐私政策、退款政策页面 URL。

建议：开发阶段先使用配置占位符，发布生产环境前必须替换，不在前端代码中散落硬编码。

## 2. 海外上线前必须确认

### Q3 首发销售地区与税务方案

- 需要确认 Stripe 账户注册国家/地区、首发允许购买的国家/地区，以及是否启用 Stripe Tax。
- 建议：首发只使用 USD 和 Stripe Checkout；税费由 Stripe Tax 根据购买位置计算，先不自建税务引擎。
- 具体可销售地区、税务登记义务和价格是否含税，需要结合实际经营主体由税务/法律专业人员确认。

### Q4 账户删除后的财务与审计数据

- 已确定：账户删除有 30 天宽限期；用户可下载仍在保留期内的资产；作品自生成完成起保留 30 天；导出 ZIP 有效 24 小时。
- 尚未确定：Stripe 订单、点数账本、安全日志和管理员审计分别保留多久。
- 建议：图片资产按既定期限物理删除；财务与防欺诈所需记录按适用法规保留，并尽早移除邮箱、姓名等非必要个人字段或改为不可逆匿名标识。
- 最终期限应由经营主体所在地和首发销售地区的合规要求确定。

### Q5 Cookie、分析与隐私同意

- 需要确认首发是否接入非必要分析、广告或行为追踪工具。
- 建议：MVP 只启用登录、支付和安全所需 Cookie，不接广告追踪；产品分析采用最小化事件和匿名标识。
- 如果加入非必要追踪，应补充 Cookie Banner、同意记录和撤回入口。

### Q6 退款与支付争议规则

- 点数属于一次性预付数字服务，尚未确定未使用点数是否可退款、退款后如何回收余额，以及余额已消费时如何处理。
- 建议：首版仅由支持邮箱受理；未消费点数可按适用法律人工退款，Webhook 更新订单并冲销对应余额；已消费部分进入人工审核。
- 退款政策必须在 Stripe 生产上线前写入用户可见条款。

## 4. 已冻结基线摘要

- 每任务最多 20 个主体；每主体生成 3 个方案并消耗 1 点。
- 新用户赠送 6 点；首发点数包为 `$2.99 / 30`、`$6.49 / 75`、`$12.99 / 180`。
- 模型为 `gpt-image-2`、`medium`；API Key、模型和 Skill 仅由平台方配置。
- MVP 只支持 6 组、25 个核心设置，不提供高级模式。
- 支持 16、20、24、32、48、64、128、256、512、1024px PNG；背景关闭时交付透明 PNG。
- 用户作品保留 30 天；账户删除宽限期 30 天；数据导出 ZIP 有效 24 小时。
- 购买点数和新用户赠送的 6 点均永久有效。
- 每个用户最多同时运行 1 个生成任务；生成期间可以编辑下一份本地草稿。
- Generate 提交成功并扣点后不可由用户取消；失败按既定规则自动重试或返还。
- 仅支持通用 UI 图标创作，不承诺品牌复刻；禁止违法、仿冒、侵权导向及受保护角色请求，MVP 通过支持邮箱处理申诉。
- 支持单张 PNG 下载和选中结果 ZIP 下载。
- 删除账户时导出用户资料、订单、点数账本、账单摘要，以及仍有效的 PNG 与 `manifest.json`。
- 不建设完整运营后台，只提供任务查询/重试、订单/Webhook 查询、人工调点与审计。
