# 2026-09-20 图标生成画布、收藏回收与下载交接

## 本轮范围

本轮继续收口 `/create` 项目级图标工作区，重点完成收藏与回收的批量操作、生成图标下载详情、单色改色、画布视角与恢复定位、异常反馈以及交互回归。实现继续遵守“UI 交互响应优先”：可恢复操作先更新局部界面，后台请求失败再回滚；画布操作不通过整页刷新同步。

## 画布、选择与布局

- 页面默认进入选择模式；选择单图时以单图中心平滑聚焦并放大，平移模式双击图组或单图会切换为选择模式后聚焦。
- “适应画布”按风格预览与全部可见图组的联合边界计算视角，并避开左右工具区与底部输入区。
- 自动整理以风格预览图正下方为锚点，根据图组面积形成间距一致的紧凑矩形，整理完成后自动聚焦并保存位置。
- 恢复回收的图组或单图时优先回到保存位置；位置缺失、无效或节点无法定位时自动整理，避免资源恢复到不可见区域。
- 图组横向成员列表支持鼠标拖动和滚轮横向滚动，同时保留点击选择能力。
- 输入区持续显示最近选中的子风格；切换主风格时保留各子风格选择与菜单状态。

## 收藏与回收

- 收藏和回收弹窗支持图组、单图两个分类，以及整卡点击选择、全选、半选状态和底部批量操作。
- 收藏支持多选下载 ZIP、批量取消收藏；回收支持批量恢复与批量永久删除。
- 新增项目级批量接口，服务端校验项目归属、收藏状态、回收状态和单图归属；批量目标去重并限制数量。
- 单项及批量永久删除使用一次确认弹窗；确认后立即执行，不再叠加第二次确认。
- 单图收藏卡片提供定位、下载和取消收藏；下载不再直接落 SVG，而是打开统一下载详情弹窗。
- 从单图收藏打开下载弹窗时，左右循环仅包含当前项目仍有效、未回收的收藏单图；从图组收藏打开时，仅在收藏图组范围循环。
- 恢复操作继续先关闭弹窗并局部更新；请求成功后聚焦原目标，失败时恢复一致状态并显示提示。

## 下载详情与颜色

- 画布图组、画布单图、图组收藏和单图收藏统一复用生成图标下载详情弹窗。
- 弹窗支持 SVG、PNG、WebP、24–1024px 尺寸、代码预览与复制；图组下载打包为 ZIP。
- 图组模式左右循环按图组切换，单图模式按入口限定的图标集合循环，均支持首尾循环。
- 单色子风格及实际只有一种可见绘制色的 SVG 显示与素材库一致的拾色器，支持纯色、线性渐变、径向渐变和透明度，并同步作用于预览、代码与导出文件。
- 下载弹窗的拾色器定位到触发按钮上方，并使用弹窗内部 portal，避免距离过远或被层级裁切。

## 异常与交互反馈

- 移除全屏“网络问题请稍后重试”错误页；页面级异常改为吐司提示并尝试局部恢复，普通加载/空状态仍使用共享状态组件。
- 画布、弹窗和颜色浮层之间补充事件隔离，避免平移手势、快捷键或焦点穿透影响弹窗操作。
- 收藏、回收、定位、下载、取消收藏等按钮补齐一致的 hover/focus 提示和深浅主题状态。
- 收藏与回收卡片保持内容自适应高度，动作按钮不遮挡名称，边缘提示通过调整方向避免被弹窗裁切。

## 接口

- `GET /api/projects/[projectId]/favorite-download`：下载已校验的收藏图组或收藏单图 ZIP。
- `PUT /api/projects/[projectId]/svg-sets`：支持 `removeFavorite` 与 `deletePermanently` 批量操作，最多 200 个去重目标。
- 单图批量永久删除会同步图组 plan/count；删除最后一张图标时删除整个图组。
