# 图标素材库与辅助网格预览实现方案

更新：2026-09-08。状态：设计方案，非完成报告；除明确记录的浏览器操作外，不代表功能已经验证或上线。

## 1. 目标与范围

登录后的导航依次为「图标素材库」「图标生成」「我的图标」。新增素材库使用自有原创 SVG，参考 Iconsax 的布局、详情预览和配置交互。保留 EASY DESIGN 品牌、现有导航行为、中英文切换和账户权限。素材库不调用生成 Worker、不消耗生成点数。

用户已要求先将参考站的辅助网格组件接入现有交互图标、插画图标实时预览区；这是独立的第一阶段，不意味着整套素材库已获实施验收。

参考站：https://app.iconsax.io/ 。自有素材工作台：`/Users/s2/Documents/ChatGPT/esdesign-icongen/experiments/svg-generation-runs/coverage-001-r321/workbench.html`。

不迁移参考站的品牌、广告、付费机制或图标资产；不将临时多选集合冒充账户收藏。

### 1.1 视觉还原范围（用户补充确认）

素材库不只是功能参考：组件外观、深色表面、边框、圆角、排版密度、页面布局、详情配置区、交互反馈和交互动效均以 Iconsax 为高保真还原目标。不是用现有通用卡片重新设计一套。站点外壳的 EASY DESIGN 导航、品牌和账户入口保持不变；素材库内容区采用参考页面的视觉语言。

| 层面 | 还原内容 | 验收方法 |
| --- | --- | --- |
| 页面 | 分类/搜索/风格标签/网格/详情的层级与空间关系 | 相同视口并排截图，核对宽度、间距及对齐 |
| 组件 | 表面色、细边框、圆角、字号、辅助网格、配置控件 | 默认、hover、focus、选中、禁用逐态对比 |
| 交互 | 点击打开详情、样式切换、配置展开收起、即时预览 | 按同一操作序列比较行为和状态保留 |
| 动效 | 弹层进出、控件展开、选中反馈、hover过渡 | 实测属性、持续时间、缓动、方向与退出行为后实现 |

实施前补录未验证状态；动效持续时间和缓动不能仅凭静态截图标成“1:1”。尽量用 opacity/transform 等低成本属性；若参考站存在裁切、键盘不可用或小屏溢出，修复这些问题，不复制缺陷。遵循 reduced-motion。还原视觉和行为，不引入参考站私有代码依赖。

### 2.3 弹层与控件过渡动效明细

目前操作记录为离散截图，未测得动画过程、持续时间与缓动。以下是必须补测的清单，不是已经确认的动画参数；禁止先填 200ms/300ms 等经验值并称为 1:1。

| 对象 | 必须观察的过程 | 需要记录的结果 |
| --- | --- | --- |
| 详情打开 | 淡入、缩放、位移是否存在；遮罩是否同步出现 | 起止 opacity/transform、方向、原点、时长、延迟、缓动 |
| 详情关闭 | 是否反向播放；退出结束后卸载还是直接隐藏 | 退出属性、时长、卸载时机；不同关闭入口是否一致 |
| 颜色面板展开 | 淡入或缩放是否存在，原点是否靠近按钮 | 定位锚点、transform-origin、起止值、时长、缓动 |
| 颜色面板关闭 | 外部点击与再次点击按钮是否使用相同过渡 | 关闭触发规则、退出参数 |
| Pure/Gradient 切换 | 高度直接变化还是平滑变化；内容是否淡入淡出 | 高度起止值、布局影响、内容进出顺序及各自时长 |
| 风格选中 | 底板直接换位还是滑动；图标是否过渡 | 背景/位移/透明度变化及持续时间 |
| hover 移入移出 | 哪些属性变化；移出是否与移入对称 | 属性列表、两方向起止值、时长和缓动 |

补测记录必须附视口、操作步骤和截图/连续帧或可读取的样式证据。观察不到动画时记录“未观察到”，不强行添加。实现后再验证快速开关、动画中切换、焦点恢复与 reduced-motion；参考站缺陷不复制。

此阶段结论：辅助网格几何结构已有实施依据，但整个素材库的像素级与动效还原规格尚未完成测量验收。

## 3. 页面与路由

| 路由 | 内容 | 行为 |
| --- | --- | --- |
| `/library` | 搜索、分类、风格、素材网格 | 查询参数保存筛选；更新不清空已有列表 |
| `/library/[designId]` | 单图详情 | 从列表进入时覆盖弹层；直接访问时可独立展示 |
| `/library?favorites=1` | 已收藏素材 | 登录态读取账户收藏，可叠加搜索 |

建议查询参数：`q`、`category`、`style`、`favorites`、`cursor`。筛选变化重置分页，不重置其他筛选。路由返回恢复滚动位置和搜索条件。中英文显示标签不作为稳定 ID。

桌面：分类区、主网格、按需打开的收藏区；详情不把列表布局挤窄。小屏：分类折叠、标签横向滚动、配置项换行、详情自身滚动；所有主要按钮保持至少 44px 触摸目标。不能照搬参考窄屏颜色面板超出视口的问题。

## 5. 第一阶段：辅助网格接入

现有接入点：

- `apps/web/src/features/generation/components/background-preview.tsx`：交互图标。
- `apps/web/src/features/generation/components/app-icon-style-selector.tsx`：插画图标。
- `apps/web/src/app/globals.css`：现有画布和响应式样式，已有修改必须保留。

新增共享组件，使用固定 `viewBox` 的代码原生 SVG 重绘圆角框、圆与参考线。禁止截图贴图、禁止引入远程图片依赖。组件不需要状态或额外请求。

图标层与网格层作为同一预览容器的兄弟元素，网格定位于后方；`aria-hidden`、不可聚焦、`pointer-events: none`，不阻断任何控件。网格使用局部类名，不能误伤预览图标中的 path 和 circle。两种模式共用几何与线宽，颜色与暗色画布保持低对比；不添加黑色底板。

保留现有预览宽高、图标大小百分比、透明度、圆角、风格切换及入场动画；仅添加辅助网格，不复制参考站较小的图标尺寸。网格不写入生成请求，不进入下载图像。实心背景遮住后方部分线条属于正确图层关系，不应把辅助线强行画到图标上。

验收：交互 linear/filled、透明/单色/渐变/圆形背景、插画全部可选风格、宽屏和手机；切换前后图标包围盒尺寸不变；网格无裁切、无滚动条、无操作遮挡。截图与参考同尺寸对比外框、圆、交点和线条对比度，记录差异后修正。

## 6. 素材与渲染核心

工作台当前约 24 个设计、144 个风格变体，是试点数据，不视为完整生产素材库。提取目录索引与按需加载的变体；不要将全部 SVG 嵌进首屏 JS。

每个变体记录 `designId`、`style`、版本、内容哈希、viewBox、路径数据和能力标记。能力至少包括 `supportsStroke`、`supportsColor`、`supportsGradient`；当前工作台部分包装器声明不支持线宽，必须逐项检查后开放，不能展示无效滑块。

渲染管线：原始受审 SVG → 已验证配置 → 确定性 SVG → 预览 / 代码 / 位图。路径与多色语义保持，不对所有节点盲目覆盖 fill。渐变定义 ID 按实例隔离，避免列表多个 SVG 相互引用。

导入限制：只允许白名单 SVG 元素和属性；拒绝 script、foreignObject、事件属性、外链及危险 URL。素材更新版本化，不能覆盖后让收藏悄悄指向另一图标。

## 7. 数据模型与权限（拟定，迁移前核对现有 Schema）

| 表 | 核心字段与约束 |
| --- | --- |
| `library_designs` | id、slug 唯一、name_zh/en、category、keywords、published、version |
| `library_variants` | id、design_id 外键、style、version、asset_path、content_hash、capabilities；设计+风格+版本唯一 |
| `library_favorites` | user_id、variant_id、created_at；用户+变体唯一 |

普通用户只读取已发布素材；仅管理员可导入/发布。收藏 RLS 限制 `auth.uid() = user_id`，新增必须引用可访问变体。服务端仍验证登录身份，不能接收客户端 user_id 作为授权依据。

收藏颗粒度为具体风格变体；纯色、尺寸等临时导出配置不改变收藏身份。素材退役后显示不可用并可取消收藏，不因一个坏项使整个列表失败。生成作品的 `generation_favorites` 保持独立；如统一入口，以来源分组展示而非混用 variant_id。

## 8. API 契约草案

| 方法与路径 | 入参 | 返回/行为 |
| --- | --- | --- |
| GET `/api/library` | q/category/style/cursor/limit | 轻量索引、nextCursor；limit 有上限 |
| GET `/api/library/[designId]` | 可选版本 | 六种可用变体、能力、资源版本 |

接口采用项目既有错误结构和请求安全校验；具体路径在实施时与现有目录核对。批量下载首期在客户端基于受审资产生成，数量和体积均设上限；超过上限提示分批，不给 4GB 服务器新增无界渲染任务。

## 9. 详情、收藏和导出交互

打开详情不自动收藏。切换风格保留兼容配置，不兼容配置降级并提示。关闭支持按钮、遮罩和 Escape；弹层内部点击不能关闭；焦点返回触发图标。辅助网格仅用于预览。

收藏按钮区分未收藏、已收藏、请求中、失败；失败回滚乐观状态并 Toast。快速重复点击串行化或合并最终意图；双标签返回页面时重新校验。收藏区点击选择不关闭，多选状态与账户持久收藏是两个概念；关闭收藏区不取消收藏。

导出首期 SVG、PNG、WebP；代码目标复用工作台已有 SVG/Vue/React/HTML/Svelte/Web Components，并逐项编译或渲染验收。异步位图导出开始时冻结 SVG、尺寸、格式和文件名，不能在图片加载回调重新读取已切换的当前图标状态。避免工作台已有的全局状态竞态。

透明背景保留 alpha；渐变在 SVG 中内嵌定义；不包含辅助网格、广告或页面底色。复制失败提供可手动选择的代码。单项失败不取消整个 ZIP，明确列出失败项与重试入口。

## 10. 性能、错误和可访问性

首屏只请求目录及可见素材，搜索短延迟防抖，旧请求可取消，最新请求结果才可提交。筛选时保留旧内容并显示局部忙碌状态，避免整页骨架闪烁。资源使用内容哈希缓存；账户收藏禁止公共缓存。没有基准测试前不加入全风格后台预热。

首期建议每页 60 个设计，达到可观测瓶颈后再评估虚拟化。记录首屏可交互时间、查询耗时、SVG 请求数与转移字节、详情首绘和导出耗时；本地与部署环境分别测冷/热缓存，不以本地结果代替线上。

Toast 用于短暂操作错误；加载失败区域必须保留重试入口。所有图标按钮具有可访问名称，选中状态可被读屏识别。支持 Tab/Shift+Tab、Escape、200% 缩放和 reduced-motion。
