# 产品概览

## 产品定位

Bamboo IconGen 是一个英文优先、支持中英文切换的小型网站，帮助独立开发者、产品经理和小团队通过结构化设计设置，一次生成一组风格统一、可直接下载的 UI 图标 PNG。

## 核心价值

- 减少从产品概念到视觉方案的时间。
- 一次支持多个图标主体，每个主体提供 3 个方案，方便用户比较选择。
- 使用 6 组 25 个核心设置引导设计方向，并由平台 Skill 转换为模型提示词。
- 生成过程异步执行，用户可以离开后返回查看。
- 使用预付点数包形成简单清晰的付费闭环。

## 核心用户旅程

1. 用户访问英文首页并了解产品能力。
2. 用户注册或登录。
3. 用户添加一个或多个 UI 图标主体，设置颜色、背景、6 组核心设置和尺寸。
4. 系统校验设置和点数并创建批量生成任务。
5. 系统为每个主体异步生成 3 个方案并展示真实任务进度。
6. 用户按主体比较、选择和标记方案，下载单张 PNG 或选中结果 ZIP。
7. 点数不足时通过 Stripe Checkout 购买点数包。

## MVP 成功标准

- 用户能够完成登录、生成、查看结果、下载和购买点数的完整闭环。
- 单次任务支持多个主体，每个主体稳定返回 3 个独立方案或明确的可恢复失败状态。
- 支付、扣点和失败返还均具备幂等与可追溯性。
- 英文界面可在桌面和移动浏览器正常使用。
