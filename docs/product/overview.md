# 产品概览

## 产品定位

AI Icon Generator 是一个英文优先的小型网站，帮助独立开发者、产品经理和小团队根据 App 产品功能与风格描述，快速生成可下载的 App Icon 方案。

## 核心价值

- 减少从产品概念到视觉方案的时间。
- 一次提供 4 个方向，方便用户比较选择。
- 生成过程异步执行，用户可以离开后返回查看。
- 使用预付点数包形成简单清晰的付费闭环。

## 核心用户旅程

1. 用户访问英文首页并了解产品能力。
2. 用户注册或登录。
3. 用户输入 App 功能、核心意象和风格描述。
4. 系统校验点数并创建生成任务。
5. 系统异步生成 4 个 Icon 方案。
6. 用户查看历史记录并下载所选 PNG。
7. 点数不足时通过 Stripe Checkout 购买点数包。

## MVP 成功标准

- 用户能够完成登录、生成、查看结果、下载和购买点数的完整闭环。
- 单次成功任务稳定返回 4 个独立结果。
- 支付、扣点和失败返还均具备幂等与可追溯性。
- 英文界面可在桌面和移动浏览器正常使用。
