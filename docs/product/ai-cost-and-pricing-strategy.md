# AI 生成成本与点数套餐策略

文档版本：0.1
更新日期：2026-09-03
状态：经营方案草案，待真实 `usage` 数据校准后定版

本文定义 Bamboo IconGen 的 Image2 成本核算口径、免费服务边界、首发套餐建议和月度成本控制线。产品与研发在设计点数、重试、细节调整和运营监控时，应同时参考本文与[作品、支付与运营业务模块需求](./works-billing-admin-requirements.md)。

## 1. 当前生成单位

- 1 点对应 1 个图标主体。
- 每个主体首次生成固定交付 3 个方案，因此基础生成至少调用 Image2 3 次。
- 用户选择的 PNG 尺寸、预览图、缩略图和 SVG 派生处理在本地完成，不额外消耗 Image2 token。
- 系统质量重试、用户主动重新生成和细节调整都会产生新的 Image2 调用成本。
- 插画风格生成会携带风格参考图；细节调整还会携带当前原图，因此除输出图像 token 外，还会产生文本及图像输入 token。

## 2. 成本计算口径

GPT Image 2 按实际 token 计费。2026-09-03 查询到的官方公开口径为：图像输入 `$8 / 1M token`、缓存图像输入 `$2 / 1M token`、图像输出 `$30 / 1M token`；文本输入和输出另计。实际账单仍以当前模型、网关和 OpenAI 账单为准。

当前代码尚未完整持久化 Image2 响应的 `usage`，因此现阶段不能把“每张图”定义为固定 token。预算阶段采用以下保守区间：

| 成本对象 | 规划估算 |
| --- | ---: |
| 单张 high 图，含常规提示词和参考图输入 | `¥1.0–¥1.6` |
| 一个主体首次生成 3 个方案 | `¥3.0–¥4.8` |
| 首次生成加正常系统质量重试 | `¥3.5–¥5.8` |
| 纳入免费重新生成和免费细节调整后的平均每点成本 | `¥6–¥9` |
| 重度用户每点成本 | 可能达到 `¥12–¥18` |

正式成本公式：

```text
每点真实成本 =
  首次生成成本
  + 系统质量重试成本
  + 用户免费重新生成平均成本
  + 用户免费细节调整平均成本
  + 存储、流量及派生处理成本
```

## 3. 免费服务规则

### 3.1 重新生成

- 用户主动重新生成不扣点。
- 系统失败、质量检测失败和缺失方案补齐不扣点，也不计入用户免费次数。
- 当前版本不设置用户可见的重新生成点数费用；同一个方案正在生成时禁止重复提交。
- 重新生成必须复用首次生成的完整风格、背景、尺寸和一致性参数，并使用幂等与并发锁避免重复任务。
- 运营侧需要监控主动重新生成率和异常高频调用；后续若需增加次数边界，必须作为新的产品与计费决策单独评审，不能静默扣点。

### 3.2 细节调整

- 每个方案分别免费赠送 3 次细节调整；方案 1、2、3 独立计数，一个主体最多包含 9 次免费调整。
- 成功生成出可供用户比较的新图时计为一次；用户是否最终保存新图不改变已产生的模型成本。
- API 错误、系统错误、透明背景检测失败等平台侧失败不消耗免费次数。
- “还原”只执行已有版本切换，不调用 Image2，不消耗次数。
- 单个方案 3 次额度用完后，第 4 次起每次调整消耗 1 点。扣点与调整任务创建必须在数据库同一事务完成；平台生成失败自动幂等返还，成功生成后即使用户不采用也不返还。

> 每方案 3 次免费额度及超额每次 1 点是当前产品规则。成本模型必须按一个主体最多 9 次免费调整进行压力测算，并通过真实使用率校准套餐毛利。

## 4. 首发套餐建议

| 套餐 | 点数 | 建议售价（USD） | 单点价格 | 定位 |
| --- | ---: | ---: | ---: | --- |
| 体验包 | 5 | `$6.99` | `$1.40` | 偶尔使用 |
| 创作包 | 20 | `$24.99` | `$1.25` | 个人设计师，默认推荐 |
| 专业包 | 50 | `$54.99` | `$1.10` | 高频创作者 |
| 团队包 | 100 | `$99.99` | `$1.00` | 小型团队 |

每一点默认包含：

- 1 个图标主体；
- 首次生成 3 个方案；
- 失败方案重新生成不扣点；
- 每个方案独立包含 3 次免费细节调整；
- 原图及用户选择尺寸的 PNG 下载；
- 对支持的风格提供可选 SVG。

定价定版前应以真实平均成本的 `2–2.5` 倍作为目标单点售价，以覆盖支付手续费、退款、存储、流量、赠送额度和质量波动。

## 5. 每月 ¥2,000 运营预算

| 成本类别 | 建议月预算 |
| --- | ---: |
| 云服务器、数据库、对象存储 | `¥300–¥400` |
| 域名、邮件、监控等摊销 | `¥50–¥100` |
| 异常重试和突发费用预留 | `¥200–¥300` |
| Image2 模型预算 | `¥1,200–¥1,400` |
| 合计 | 约 `¥2,000` |

按每点平均综合成本 `¥7` 估算，每月安全承载量约为 170–200 个实际消费点数；若用户集中用满全部赠送额度，安全承载量可能下降到 100–140 点。

运营保护线：

- 模型月消费达到 `¥1,000`：内部预警并复核异常用户和失败率。
- 达到 `¥1,200`：收紧赠送活动和异常重试策略。
- 达到 `¥1,400`：停止新增赠送额度，付费任务进入限速队列。
- 不得通过直接丢弃已付费任务控制预算；必须保留排队、退款或点数返还闭环。

## 6. 必须补充的成本遥测

每一次 Image2 请求需要记录：

- 模型及快照版本；
- 文本输入 token；
- 图像输入、缓存输入和输出 token；
- 供应商返回的实际费用或按价格版本换算的费用；
- 操作类型：首次生成、系统重试、主动重新生成、细节调整；
- 风格、背景类型、是否使用参考图；
- 任务、主体、方案、用户和价格版本引用；
- 请求是否成功、失败原因及重试序号。

成本记录不得包含用户密钥、完整内部提示词或原始私有图片内容。若上游没有返回 `usage`，应记录请求参数、响应尺寸、供应商请求 ID 和账单对账标识，并将本次费用标记为估算值。

至少积累 100–200 次真实生成后，输出以下指标并复核套餐：

- 单张图平均、P50、P90 成本；
- 每点平均、P50、P90 成本；
- 九种风格分别的平均成本；
- 系统重试率及其成本占比；
- 主动重新生成使用率；
- 细节调整使用率、成功率和平均尝试次数；
- 每个套餐的真实毛利率。

## 7. 定版条件


1. 成本遥测已上线且经过账单对账；
2. 至少取得 100–200 次真实 Image2 调用样本；
3. 明确主动重新生成的免费次数和超额规则；
4. 明确细节调整次数的扣减时点及失败返还规则；
5. 套餐价格已包含支付手续费和税费影响；
6. 月度预算预警、限速与退款闭环可用。
