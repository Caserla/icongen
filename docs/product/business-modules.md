# 六个业务模块

本页为模块导航。完整产品范围、两阶段核心流程和模块间闭环见 [Bamboo IconGen PRD](./product-requirements.md)。

## 1. 用户信息

负责个人资料、账户状态、点数余额摘要、使用统计和账户删除入口。

正式需求与开发任务：

- [用户信息、登录与账户模块需求](./user-auth-account-requirements.md)
- [用户信息、登录与账户开发任务](../project/user-auth-account-development-tasks.md)

## 2. 登录与账户

负责邮箱注册与登录、验证、会话、退出登录和受保护页面拦截。

正式需求与开发任务与用户信息模块共用同一份账户域文档，见上方链接。

## 3. 图片生成

负责多图标主体、主体与背景颜色、图标设计风格、输出尺寸、报价、异步进度、Icon Skill 和模型调用。一次任务包含多个主体，每个主体生成 3 个方案。

正式需求：

- [图片生成模块需求](./icon-generation-requirements.md)

## 4. 作品与下载

负责批量任务历史、每主体 3 个方案预览、首选标记、权限校验、单张 PNG 和选中结果 ZIP 下载。

正式需求：

- [作品、支付与运营模块需求](./works-billing-admin-requirements.md#1-作品与下载模块)

## 5. 点数与 Stripe 支付

负责点数包、Stripe Checkout、Webhook 入账、点数账本、生成扣点、失败返还和人工调整。

正式需求：

- [作品、支付与运营模块需求](./works-billing-admin-requirements.md#2-点数与-stripe-支付模块)

## 6. 最小运营支持

只负责任务查询与安全重试、订单/Webhook 查询、人工调点和操作审计。不建设完整用户管理、数据看板、设置编辑器或模型管理后台。

正式需求：

- [作品、支付与运营模块需求](./works-billing-admin-requirements.md#3-最小运营支持模块)

## 模块需求统一结构

每个模块均按以下结构维护：

- 用户目标与用户故事。
- 页面和交互功能。
- 功能需求编号与优先级。
- 业务规则和状态流转。
- API 与数据字段。
- 异常场景和错误提示。
- 埋点与运营指标。
- 验收标准和测试场景。
