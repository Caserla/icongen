# 六个业务模块

## 1. 用户信息

负责个人资料、账户状态、点数余额摘要和账户删除入口。

正式需求与开发任务：

- [用户信息、登录与账户模块需求](./user-auth-account-requirements.md)
- [用户信息、登录与账户开发任务](../project/user-auth-account-development-tasks.md)

## 2. 登录与账户

负责邮箱注册与登录、验证、会话、退出登录和受保护页面拦截。

正式需求与开发任务与用户信息模块共用同一份账户域文档，见上方链接。

## 3. 图片生成

负责描述输入、点数校验、异步任务、Icon Skill、4 个方案、状态反馈、失败重试与点数返还。

## 4. 作品与下载

负责生成历史、任务详情、4 个结果预览、权限校验和单张 PNG 下载。

## 5. 点数与 Stripe 支付

负责点数包、Stripe Checkout、Webhook 入账、点数账本、生成扣点、失败返还和人工调整。

## 6. 运营后台

负责管理员权限、用户/任务/订单查询、异常处理、任务重试、账户限制、人工调点和审计日志。

## 细分模板

后续每个模块统一按照以下结构细化：

- 用户目标与用户故事。
- 页面和交互功能。
- 功能需求编号与优先级。
- 业务规则和状态流转。
- API 与数据字段。
- 异常场景和错误提示。
- 埋点与运营指标。
- 验收标准和测试场景。
