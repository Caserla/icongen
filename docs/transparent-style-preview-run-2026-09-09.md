# 九风格透明主体预览

## 执行方式

用户确认：构建主体描述，通过现有「插画图标」页面生成，不直接调用图像服务。每个主体固定三个候选；每种风格最终选择一个作为透明前景。输出选择128px，背景设置为透明。不得把背景烘焙到主体。

## 主体描述

所有方案均为原创演示品牌，要求真实RGBA、无底板/天空/地面/背景投影、空隙透明，留4%透明边缘。
