# 管理后台与 CD-Key 运营手册

文档版本：1.0
适用范围：仅使用 CD-Key 充值的首期生产环境

## 1. 已实现范围

受保护的 `/admin` 管理后台提供四类能力：

- 数据总览：用户量、当日任务、队列状态、失败数、点数消耗/返还、CD-Key 到账、运行时并发配置，以及近 14 天生成任务/点数消耗曲线。
- 只读排查：用户余额、生成任务、错误摘要和管理员审计日志。
- CD-Key 发放：按批次生成 1–500 个兑换码，设置单码点数、到期时间、渠道和内部备注。
- CD-Key 止损：停用整批尚未兑换的兑换码，强制填写原因并写入审计日志。

后台第一阶段不提供删除用户、直接改余额、删除账本或重跑生成任务等高风险写操作。

管理员登录产品工作区后，可从顶部头像菜单的“管理后台”进入 `/admin`。该入口由服务端读取 Auth `app_metadata.role` 后决定是否展示；普通用户既看不到入口，也无法直接访问后台页面或 API。

## 2. 权限模型

- 管理员身份保存于 Supabase Auth `app_metadata.role = admin`，不能由浏览器自行修改。
- 页面和所有 `/api/admin/*` 接口都在服务端再次校验登录状态、账户状态和管理员角色。
- Service Role 只存在于服务端。普通 `authenticated` / `anon` 角色不能直接读取兑换码、批次或审计表。
- 管理员写操作记录操作者、目标、原因、时间和必要的元数据。

授权命令：

```bash
npm run admin:grant -- user@example.com
npm run admin:revoke -- user@example.com
npm run admin:create -- new-admin@example.com "Display Name" existing-admin@example.com
```

创建命令会在终端中隐藏输入初始密码，同时完成邮箱确认、昵称、管理员角色和审计记录。撤销脚本会拒绝移除最后一个管理员。角色变化后，用户需要重新登录以刷新令牌。

## 3. 上线步骤

1. 在目标 Supabase 项目执行 `infra/supabase/migrations/0023_admin_operations_and_cd_key_batches.sql`。
2. 确认生产服务端已配置 `SUPABASE_SERVICE_ROLE_KEY`，且该变量没有进入任何 `NEXT_PUBLIC_*` 配置、浏览器包或日志。
3. 通过 `admin:grant` 指定至少两个受控管理员账户，避免单点失联。
4. 管理员重新登录，访问 `/admin`，验证数据总览、五个页签和普通用户 403。
5. 生成最小测试批次并立即导出 CSV；确认数据库没有保存明文码。
6. 用测试用户兑换一个码，核对余额与 `credit_ledger`；再停用该批次，确认未兑换码均不可使用。

## 4. CD-Key 标准流程

1. 填写有业务含义的批次名、点数、数量、渠道、到期时间和备注。
2. 点击生成后立即下载 CSV。明文仅在本次响应中返回，关闭或刷新页面后无法恢复。
3. 通过受控渠道分发，不在工单、聊天群或日志中粘贴完整批次。
4. 发现泄漏时，在后台填写原因并停用整批；已兑换码不会回滚，需通过账本单独调查。
5. 审计页核对创建与停用记录。

## 5. 验收用例

| 编号   | 操作                                        | 预期结果                                      |
| ------ | ------------------------------------------- | --------------------------------------------- |
| ADM-01 | 未登录访问 `/admin`                         | 跳转登录或拒绝访问                            |
| ADM-02 | 普通用户访问 `/admin` 和任一 `/api/admin/*` | 页面不可见，API 返回 403                      |
| ADM-03 | 管理员访问后台                              | 五个页签可见，总览加载成功                    |
| ADM-04 | 管理员从顶部头像菜单点击“管理后台”          | 入口可见并进入 `/admin`；普通用户不展示       |
| ADM-05 | 快速切换用户、任务、CD-Key 和审计页签       | 迟到响应不会覆盖当前页签数据                  |
| ADM-06 | 查看数据总览                                | 展示近 14 天任务数与点数消耗曲线              |
| CDK-01 | 创建 3 个、每码 20 点的批次                 | 返回 3 个不同明文码；列表出现新批次；写入审计 |
| CDK-02 | 刷新后台                                    | 不再返回明文码，只显示批次统计信息            |
| CDK-03 | 同一码并发兑换两次                          | 仅一次到账，另一请求返回已兑换                |
| CDK-04 | 停用批次后兑换未使用码                      | 返回已停用，不增加余额                        |
| CDK-05 | 停用时不填原因                              | 前端与服务端均拒绝                            |
| CDK-06 | 数量为 0、501 或点数越界                    | 服务端返回参数错误，不创建批次                |
| AUD-01 | 创建/停用批次                               | 审计记录含操作者、动作、目标与原因            |
