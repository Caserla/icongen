# ADR-0001：MVP 产品范围

- 状态：已被 ADR-0002 部分替代
- 日期：2026-08-19

## 决策

首版产品采用以下范围：

- 英文优先。
- 原决策“一次任务生成一个 Icon 概念的 4 个方案”已由 ADR-0002 替代。
- 首版下载 PNG。
- 不建设在线编辑器、公开社区、团队协作或订阅制。

## 已由后续专项确认

- PNG 支持常用尺寸多选；模型生成母版后由服务端派生。
- 用户关闭背景时输出透明背景 RGBA PNG；开启时按背景设置输出。
- 每个主体固定包含 3 个方案并消耗 1 点；点数包价格见 PRD 2.0。

以上内容已在图片生成和商业定价专项中确认。
