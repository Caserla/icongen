日期：2026-09-19。范围：`/create` 实际入口及由该页面打开的浮层、弹窗、下载和接口。依据：当前工作区代码、项目 UI 响应优先准则及已确认的用户交互要求。

**执行状态：本文全部用例未执行。** 本轮只进行代码梳理与用例设计；历史修复和历史自测不能作为本轮通过证据。表内预期是验收目标，不能据此认定功能已实现。代码静态疑点见末尾。

## 1. 范围、优先级与执行方法

- P0：数据隔离、误操作、丢失数据、无法生成/收藏/恢复等主流程阻塞。
- P1：主要交互、反馈、键盘、状态切换、持久化和回归缺陷。
- P2：视觉细节、边界兼容和体验完善。
- 每条用例需记录：环境、数据标识、实际结果、通过/失败/阻塞、截图或录像、相关请求状态。网络断言与视觉断言分别检查。
- 同一行的枚举值为参数化用例，每个值独立执行并记录，不能只测第一个就判整行通过。
- 修改数据、生成资源和故障注入在专用测试项目/测试账号执行；模型生成使用小批量真实冒烟，竞态和超时通过测试环境可控响应复现。
- “立即反馈”的建议目标为操作后 100ms 内出现状态变化，慢网不阻塞输入/画布；这是待采用的验收预算，不是当前测量结论。

## 16. 代码审阅发现的重点风险（不是本轮已复现缺陷）

1. **收藏 × 裁切风险**：当前 × 使用负 top，父列表 `overflow-y:auto`；只检查按钮是否在视口内不足以判断被父滚动容器裁切。需截图与实际点击验证第一行顶部完整圆形，FAV-04 优先。
2. **恢复失败反馈风险**：恢复先关闭弹窗，失败路径仅设置弹窗内部 failed；网络异常也需确认被捕获。用户可能看不到错误，REC-07 优先。
3. **单图收藏定位语义**：当前单图收藏卡片传入组 ID 调用定位图组。需要确认收藏卡片应定位单图还是整组；建议与画布单图聚焦一致。FAV-05 在规则确认前记录为待定，不能机械判通过。
4. **手动渐变完整性**：输入 picker 支持角度、位置、透明度，但实时预览回调仅组装部分渐变字段；检查预览、请求、SVG 三者一致，COL-07 优先。
5. **平移双击时序**：当前手势识别窗口与详情延迟不同；双击时跨节点、拖动后点击、不同点击间隔应分别验证，CAN-05/06 优先。
6. **弹窗与画布快捷键/捏合**：已对 wheel 排除 dialog；其他手势监听和全局快捷键仍需逐条测试，ACT-12、CAN-15、X-14 优先。
7. **收藏与下载禁用规则**：用户要求互斥后控件保留禁用；需要明确下载是否仅请求中禁用，还是收藏完成后也禁用。建议普通收藏完成后仍可下载；ACT-08 在规则确认前记录待定。
8. **适应画布范围**：需确认适配预览图还是全部生成组；建议涵盖可见资源集。CAN-16 独立记录，不能用任意倍率变化代替验收。
9. **跨项目晚到响应**：恢复、主题推荐、保存、回收列表都涉及异步回写，优先验证 projectId 与响应归属，不只验证菜单显示名。
10. **数量/失败布局**：当前回收单图保留 spacer 维持排列；要同时验证视觉无残留和其他组不移动，避免“删空后仍有框”复发。
