## 发现的问题

- 在约 847px 宽的浏览器视口，选择单图自动聚焦到 120% 后，图组右侧的收藏/下载/回收操作栏可能位于可视区外。通过触控板横向平移可以操作，但不符合操作入口立即可见的期望。应单独修复单图聚焦时为右侧操作栏预留空间，或调整操作栏停靠位置。

## 回归关注

1. 单图与整组收藏/回收互斥仅禁用操作，不隐藏按钮或改变布局。
2. 回收与恢复不得整页刷新，不得挪动其它图组；恢复后 SVG 必须实际显示。
3. 切换项目或重新加载时，以项目后端状态为准；素材库数据不得混入。
4. 弱网、接口错误及响应乱序须验证乐观回滚、幂等和提示。
5. 永久删除属于不可逆操作，必须保留两次独立模态确认；按钮文案连续变化不能替代确认弹窗。
6. 目标数据库必须已应用 `0045_project_svg_icon_delete_policy.sql`，否则单图永久删除会因 RLS 失败。
