# 前后端与部署安全：基本闭环到生产级闭环

更新时间：2026-09-03

## 1. 两级完成标准

### 基本闭环

面向单台云服务器、小规模受控试运营。在不改变现有产品交互的前提下，完成：

1. 登录、注册、密码、CD-Key、生成、重试、细节调整等高成本或高风险接口具备应用层限流，并返回统一 `429`。
2. Cookie 鉴权写接口具备同源、Content-Type 和请求体大小校验。
3. 全站返回基础安全响应头，浏览器不能把页面嵌入第三方 Frame。
4. 下载数量、单资源和 ZIP 总输入均有硬上限，异常不会拖垮 Web 进程。
5. Worker 日志不记录密钥、Token、签名 URL、完整 Prompt 和用户调整内容。
6. Web 和 Worker 有独立健康检查、明确退出码与单机守护进程配置；服务崩溃可自动拉起。
7. 提供最小化 Docker/Caddy 部署模板，只有 80/443 对公网开放，业务进程不以 root 运行。
8. 自动化测试、生产构建和真实 HTTP 安全用例全部通过。

基本闭环不代表可以无监督大规模开放；它允许在完成服务器人工配置后进行小流量试运营。

### 生产级闭环

在基本闭环上继续完成：Redis/Cloudflare 分布式限流、WAF、账户与全局费用熔断、异步大 ZIP、独立队列 Worker、密钥托管与轮换、数据库和对象存储备份恢复、集中日志、监控告警、漏洞/镜像扫描、正式域名 TLS 验收、隐私与数据保留规则，以及故障演练。

支付渠道当前暂停，不进入本轮基本闭环；上线时购买入口必须保持关闭。

## 2. 基本闭环实施顺序

| 阶段 | 内容 | 完成信号 |
| --- | --- | --- |
| B1 | 测试收集、安全响应头、同源写请求、请求体限制 | 默认测试覆盖嵌套用例；跨站写请求返回 403 |
| B2 | 单机应用限流、CD-Key 防猜测、高成本接口保护 | 超限返回 429；窗口结束可恢复；不同账户隔离 |
| B3 | ZIP 边界、日志脱敏 | 超限安全失败；日志无敏感字段 |
| B4 | Web/Worker 健康检查与单机部署模板 | 容器非 root；健康检查可用；异常自动重启 |
| B5 | 全量回归与真实 HTTP 验收 | 测试、类型、Lint、Build、关键 HTTP 用例全部通过 |

## 3. 生产级后续项

1. 将单机限流存储替换为 Redis，Cloudflare 同时执行边缘 IP 限流。
2. 对模型调用设置账户日限额、全局日/月预算和自动熔断。
3. 把生成和归档统一迁移到可租约、可恢复、可观测的持久队列。
4. 使用云密钥服务或 Docker secrets，完成首次轮换和吊销演练。
5. 开启 Supabase 备份/PITR，对数据库和 Storage 做恢复演练并记录 RPO/RTO。
6. 接入 5xx、登录失败、猜码、队列、费用、CPU、内存、磁盘和证书告警。
7. 完成正式域名、TLS、WAF、安全组、隐私政策、服务条款和数据保留期限人工验收。

## 4. 不影响业务原则

- 正常用户在限额内的页面和 API 行为保持不变。
- 限流只作用于写操作和高风险入口，普通页面浏览不受影响。
- ZIP 上限覆盖当前单批最多 20 个主体的正常选择；超大文件给出明确错误，不导致进程失控。
- 安全错误只返回稳定错误码，不向浏览器暴露内部异常、密钥或供应商响应。
